# Indonesian cafe webpage

A simple one-page presentational website. The design is inspired by Annisa Az Zahra, you can check her Figma profile at:
https://www.figma.com/community/file/1143814225687471258/indonesian-cafe-landing-page-soree-palembang
<br>

## Step 1: Install dependencies

```sh
npm install
```

 <br>

## Step 2: Start the project

```sh
npm start
```
